# Epic 1 Retrospective: Timer de base utilisable

Status: complete
Date: 2026-05-25

## Summary

Epic 1 delivered 5 stories for the TimeBoucle MVP.

## What went well

- Stories stayed MVP-focused.
- No backend or cloud dependency introduced.
- Tests and static build remained green.
- Sprint status stayed synchronized with implementation artifacts.

## Lessons

- Small browser-first scope made the MVP shippable quickly.
- Timestamp-based timer logic is the right baseline for browser timer drift.
- Audio browser policies require explicit user feedback and a Test Sound control.

## Action items

- Keep future features behind clear product decisions.
- Prefer PWA only after MVP manual use validates need.
- Continue committing after each story or small deliverable.
