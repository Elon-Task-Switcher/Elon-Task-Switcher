# Addendum

## User-provided source notes

- TimeBoucle is an application to switch tasks every 5 minutes.
- The idea is inspired by Elon Musk's short time-block/task-switching pattern.
- The app should play a sound when the 5-minute interval ends.
- The app should include a break system, for example 5 minutes every hour.
- The first target user is the creator.
- The project should be open source.
- Current workaround: mobile timer app, but it is not flexible and not dedicated to this workflow.
- First platform: web, deployable to GitHub Pages or another free host.
- Deadline: as fast as possible, ideally today.
- Hard refusal: not making it open source.
